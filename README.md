# Movie Project 🎥

**Movie Project** adalah aplikasi berbasis web yang menyediakan informasi tentang film, termasuk rekomendasi, detail, dan berbagai kategori film. Proyek ini dibangun menggunakan **React**, **React Router**, dan **Swiper** untuk pengalaman pengguna yang interaktif dan modern.

---

## 🚀 Fitur Utama

- **Browse Film**: Jelajahi berbagai film berdasarkan kategori.
- **Detail Film**: Lihat informasi detail tentang film favorit Anda.
- **Responsif**: Desain yang responsif dengan dukungan **Tailwind CSS**.
- **Navigasi Dinamis**: Menggunakan **React Router** untuk navigasi yang mulus.
- **Carousel**: Komponen slider interaktif menggunakan **Swiper**.

---

## 🛠️ Teknologi yang Digunakan

- **Frontend Framework**: [React](https://react.dev/) (v18.3.1)
- **Router**: [React Router DOM](https://reactrouter.com/) (v6.26.1)
- **Icons**: [React Icons](https://react-icons.github.io/react-icons/) (v5.3.0)
- **Carousel**: [Swiper](https://swiperjs.com/) (v11.1.12)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) (v3.4.10)
- **Module Bundler**: [Vite](https://vitejs.dev/) (v5.4.1)
- **Linting**: [ESLint](https://eslint.org/) dengan plugin React

---

## 📦 Instalasi dan Setup

### 1. Clone Repository
```bash
git clone https://github.com/faiqmubarok/movie-project.git
cd movie-project
```

### 2. Install Dependencies
Pastikan Anda sudah menginstal **Node.js** (v16+):
```bash
npm install
```

### 3. Jalankan Proyek Secara Lokal
```bash
npm run dev
```

Aplikasi akan berjalan di `http://localhost:5173`.

### 4. Build untuk Produksi
```bash
npm run build
```
